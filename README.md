# FocusFade — Smart Audio Dimmer

FocusFade is a smart, ultra-lightweight Windows desktop audio utility that automatically dims/lowers background music (Spotify, YouTube Music, web browsers, etc.) whenever priority applications (Discord, After Effects, Premiere, Zoom, Voice/Mic) produce sound.

## Features
- **Smart Priority Audio Ducking:** Seamlessly lower background music when voice, edit previews, or calls happen.
- **Multi-Target Background Music Support:** Monitor and dim multiple target players simultaneously.
- **Per-App Sensitivity Noise Gate:** Configure individual volume thresholds for each priority app.
- **Auto Voice/Microphone Gate:** React in real-time to your microphone input.
- **Audio-Reactive Squircle System Tray Icon:** Visual soundwave status directly in your Windows taskbar tray.
- **Picture-in-Picture (PiP) Overlay:** Draggable, compact desktop volume and meter monitor.
- **Zero Idle Overhead:** Sleeps when no audio is playing to preserve CPU & battery.
